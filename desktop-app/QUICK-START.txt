INSTALLATION (First Time Only)
─────────────────────────────────────────────────────────

1. Install Python 3.8+
   └─ Download: https://www.python.org/downloads/
   └─ ✓ CHECK "Add Python to PATH" during install!

2. Extract all files to a folder
   └─ Example: C:\TranslationProcessor

3. Double-click "start.bat"
   └─ First time will install dependencies (1-2 minutes)
   └─ Application will start automatically


═══════════════════════════════════════════════════════════
  FIRST TIME SETUP
═══════════════════════════════════════════════════════════

1. Add Company Logo & Signature:
   └─ Place "park_logo.png" in assets/ folder
   └─ Place "park_signature.png" in assets/ folder

2. Add Translators:
   └─ Click "Manage" button (next to Translator dropdown)
   └─ Click "New"
   └─ Enter name and language pairs
   └─ Upload signature image
   └─ Click "Save"
   └─ Repeat for all translators


═══════════════════════════════════════════════════════════
  DAILY USE - PROCESS A TRANSLATION
═══════════════════════════════════════════════════════════

1. Download translated Word document from Plunet to local drive

2. Open Translation Processor (double-click start.bat)

3. Load Document:
   → Drag & drop Word file onto gray area, OR
   → Click "Browse for File..."

4. Fill in Case Information:
   → Case Number (required)
   → Source Language (required)
   → Target Language (usually English)
   → Translator (select from dropdown)
   → Date (auto-filled)

5. Click "Process Translation"

6. Choose where to save the PDF

7. Wait for processing (10-30 seconds)

8. Done! PDF is ready to upload to Plunet


═══════════════════════════════════════════════════════════
  OUTPUT FORMAT
═══════════════════════════════════════════════════════════

The generated PDF contains 3 sections:

1. Translation Document (with headers/footers)
   └─ Header: Logo + Contact info
   └─ Footer: Case #, Page numbers, Language pair

2. Translator Certificate
   └─ Certification statement
   └─ Translator name & signature

3. Park Certificate
   └─ Company certification
   └─ Park employee signature

═══════════════════════════════════════════════════════════
  COMMON ISSUES
═══════════════════════════════════════════════════════════

"Python is not recognized"
  → Reinstall Python with "Add to PATH" checked

Drag-and-drop not working
  → Use "Browse for File..." button instead
  → Make sure file is .docx (not .doc)

PDF conversion fails
  → Requires Microsoft Word installed
  → App will save as .docx instead
  → Manually convert using Word

Translator list empty
  → Click "Manage" → Add translators
  → Don't forget to click "Save"
