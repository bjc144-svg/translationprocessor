NETWORK ACCESS FIX - READ THIS FIRST!
─────────────────────────────────────────────────────────

If other users cannot access your server, it's almost
certainly Windows Firewall blocking port 5000.

⚠️ IMMEDIATE FIX (Do this first!):

  1. Right-click "fix-firewall.bat"
  2. Select "Run as administrator"
  3. Follow the prompts
  4. Restart the server


═══════════════════════════════════════════════════════════
  INSTALLATION (First Time Setup)
═══════════════════════════════════════════════════════════

1. Install Python
   └─ Download from: https://www.python.org/downloads/
   └─ ✓ CHECK "Add Python to PATH" during install!

2. Extract all project files to a folder

3. Fix the firewall (IMPORTANT!)
   └─ Right-click "fix-firewall.bat"
   └─ Select "Run as administrator"

4. Start the server
   └─ Double-click "start.bat"
   └─ Note the IP address shown (like 192.168.1.100)


═══════════════════════════════════════════════════════════
  TESTING
═══════════════════════════════════════════════════════════

On the SERVER machine:
  → Open browser: http://localhost:5000
  → You should see a green success page
  → Note the IP address shown

On OTHER machines (same network):
  → Open browser: http://[IP-ADDRESS]:5000
  → Example: http://192.168.1.100:5000
  → You should see the same success page
